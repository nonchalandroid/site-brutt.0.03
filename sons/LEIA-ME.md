# Sons da loja

Pacote de sons de interface enviado pela loja (os nomes são os do pacote original; os arquivos foram
convertidos para MP3 mono 64 kbps, que todo navegador toca, inclusive o Safari do iPhone).
Quem toca é `js/sons.js` (`SOM.toca("ação")`). Para trocar um som, mude o arquivo no `MAPA` de lá.

| Ação no site | Nome no `MAPA` | Arquivo |
|---|---|---|
| Produto adicionado ao carrinho | `add` | drop_002 |
| + / − quantidade | `mais` / `menos` | tick_004 / tick_002 |
| Item removido / carrinho limpo | `remove` | minimize_008 |
| "Toque de novo pra limpar" | `aviso` | question_004 |
| Falta preencher algo / esgotado / limite de estoque | `erro` | error_004 |
| Pagamento recusado / Pix vencido | `falha` | error_006 |
| Menu de categorias, filtros | `seleciona` | select_002 |
| Setas dos carrosséis, trocar de produto | `seta` | click_002 |
| Forma de entrega / pagamento | `opcao` | toggle_002 |
| Finalizar pedido / Voltar | `avanca` / `volta` | select_007 / back_003 |
| Enviar pedido, gerar Pix, mandar no WhatsApp, perguntar à IA | `envia` | maximize_009 |
| Abrir / fechar produto, carrinho, endereço, acompanhamento | `abre` / `fecha` | open_002 / close_002 |
| Copiou código Pix / endereço | `copia` | pluck_001 |
| Endereço de entrega confirmado | `confirma` | pluck_002 |
| QR Code do Pix pronto | `pix` | glass_002 |
| Pedido mínimo atingido | `minimo` | glass_006 |
| Pagamento confirmado | `pago` | confirmation_004 |
| Pedido mudou de etapa (saiu para entrega, entregue) | `etapa` | confirmation_002 |
| Brutt IA: abrir / fechar / resposta | `ia_abre` / `ia_fecha` / `ia_resposta` | maximize_003 / minimize_003 / glass_005 |
